# Pre-launch review

This is a safety topic. Before launch, a licensed HVAC technician should review:

- [ ] Every troubleshooter path in `src/data/trees.json` (steps, time and cost ranges)
- [ ] Flame sensor cleaning instructions
- [ ] Condensate drain clearing (vinegar, wet/dry vacuum)
- [ ] Guidance that a metal-flue furnace leaking water indicates a venting problem
- [ ] Delayed ignition and scraping-noise advice (turn off immediately)
- [ ] Typical cost ranges are reasonable for 2026 U.S. pricing
- [ ] Gas-smell banner wording
