# Handover guide (for the buyer)

## Included
Domain `whyismyfurnace.com`, this repository, the Cloudflare Pages project, analytics and Search Console access, and any affiliate or lead-generation accounts listed in the sale.

## Transfer steps
1. Seller transfers this GitHub repository to you.
2. Create a Cloudflare Pages project from it: build `STAGING=0 node build.mjs`, output `dist`.
3. Seller moves the domain to your Cloudflare account (or starts a registrar transfer after the 60-day lock).
4. Seller adds you as owner in Search Console and analytics, then removes themselves.
5. Swap affiliate IDs and any lead-generation integration to your own accounts.

## Costs and upkeep
Hosting $0, domain about $11/year. Traffic peaks October to February. Add new problem guides before each heating season.
