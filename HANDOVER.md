# Handover guide (for the buyer)

## Included
Domain `excelpracticetest.com`, this repository, the Cloudflare Pages project, analytics and Search Console access, and any affiliate or payment accounts listed in the sale.

## Transfer steps
1. Seller transfers this GitHub repository to you.
2. Create a Cloudflare Pages project from it: build `STAGING=0 node build.mjs`, output `dist`.
3. Seller moves the domain to your Cloudflare account (or starts a registrar transfer after the 60-day lock).
4. Seller adds you as owner in Search Console and analytics, then removes themselves.
5. Swap affiliate IDs and the Pro checkout to your own accounts.

## Costs and upkeep
Hosting $0, domain about $11/year. Traffic is steady year-round with peaks in January and September (hiring seasons). Add a few exercises each month; each one is a new page that can rank.
