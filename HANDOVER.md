# Handover guide (for the buyer)

## What you are getting
- The domain `mynotaryexam.com`
- This repository (all source code and content)
- The Cloudflare Pages project
- Analytics and Google Search Console access
- Any affiliate and payment accounts listed in the sale

## Transfer steps
1. **Code:** the seller transfers this GitHub repository to your account (Settings → Transfer ownership).
2. **Hosting:** in your Cloudflare account, create a Pages project from the repository. Build command `STAGING=0 node build.mjs`, output directory `dist`.
3. **Domain:** the seller moves the domain to your Cloudflare account or starts a registrar transfer. Domains registered less than 60 days earlier cannot change registrar yet.
4. **Search Console and analytics:** the seller adds you as owner, then removes themselves.
5. **Monetization:** swap affiliate IDs and the Pro checkout link to your own accounts.

## Running costs
- Hosting: $0 (Cloudflare Pages free tier)
- Domain: about $11 per year

## Weekly upkeep (about 1 hour)
- Check state commissioning-office pages for rule or fee changes.
- Add one new state guide or study guide.
