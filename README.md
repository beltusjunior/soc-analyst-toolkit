# MyNotaryExam

Free notary exam practice tests and state-by-state notary guides.

- **Stack:** plain static HTML/CSS/JS generated by one Node script. No framework, no dependencies, no database.
- **Hosting:** Cloudflare Pages (free tier).
- **Build:** `node build.mjs` writes the site to `dist/`.

## Content lives in `src/`

| File | What it holds |
|---|---|
| `src/data/states.json` | State guide data (facts, steps, FAQ, sources) and the list of all states |
| `src/data/questions-general.json` | General notary practice questions |
| `src/data/questions-california.json` | California-specific questions |
| `src/guides/guides.mjs` | Study guide articles |
| `src/assets/site.css`, `quiz.js` | Styles and the practice-test widget |

To add a state: add an object to `detailed` in `states.json` (optionally with its own question file registered in `TESTS` in `build.mjs`), then rebuild.

## Staging vs. launch

Builds are **staging by default**: every page gets `noindex`, `robots.txt` blocks crawlers, and a preview banner shows.
At launch, build with `STAGING=0 SITE_URL=https://mynotaryexam.com node build.mjs`.

## Deploy (Cloudflare Pages)

Build command: `STAGING=0 node build.mjs` · Output directory: `dist`
