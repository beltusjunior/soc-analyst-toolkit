# Excel Practice Test

Interactive Excel formula practice in the browser, plus a free Excel test for job interviews.

- **Stack:** static HTML/CSS/JS generated by one Node script. No framework, no dependencies, no server.
- **Hosting:** Cloudflare Pages (free tier).
- **Build:** `node build.mjs` writes `dist/`. Staging (noindex) by default; at launch use `STAGING=0 SITE_URL=https://excelpracticetest.com node build.mjs`.
- **Tests:** `node test/formula.test.mjs` checks the formula engine against every exercise answer.

| File | What it holds |
|---|---|
| `src/assets/formula.js` | Small spreadsheet formula engine (SUM, IF, COUNTIF, SUMIF, VLOOKUP, XLOOKUP, INDEX/MATCH, IFERROR, text functions and more) |
| `src/assets/practice.js` | Interactive worksheet widget that checks answers |
| `src/data/exercises.json` | Sample sheet data and exercises (task, reference answer, required functions, hint, explanation) |
| `src/data/questions.json` | Multiple-choice interview test |
| `src/guides/guides.mjs` | Guides |

To add an exercise: add it to `exercises.json`, add its expected value to `test/formula.test.mjs`, run the test, rebuild.
If a new exercise needs a function the engine lacks, add it to the `F` table in `formula.js`.
