# whyismyfurnace

Furnace troubleshooting guides with an interactive step-by-step diagnostic tool.

- **Stack:** static HTML/CSS/JS generated by one Node script. No framework, no dependencies.
- **Hosting:** Cloudflare Pages (free tier).
- **Build:** `node build.mjs` writes `dist/`. Staging (noindex) by default; at launch use `STAGING=0 SITE_URL=https://whyismyfurnace.com node build.mjs`.

| File | What it holds |
|---|---|
| `src/data/trees.json` | Troubleshooter decision trees (questions, choices, verdicts with steps, time and cost) |
| `src/guides/guides.mjs` | Symptom guides; each one embeds the matching troubleshooter |
| `src/assets/app.js` | Troubleshooter widget |
| `src/assets/site.css` | Styles |

To add a problem: add a tree to `trees.json` and a guide with a matching `tree` key to `guides.mjs`, then rebuild.

Monetization slots: affiliate parts (filters, CO alarms, thermostats, condensate pumps), the Find a pro page (lead-generation partner or rank-and-rent), and display ads once traffic grows.
