# Boater Practice Test

Free boater safety practice test, a federal safety-equipment checker, and state boater education guides.

- **Stack:** static HTML/CSS/JS generated by one Node script. No framework, no dependencies.
- **Hosting:** Cloudflare Pages (free tier).
- **Build:** `node build.mjs` writes the site to `dist/`. Builds are staging (noindex) by default; at launch use `STAGING=0 SITE_URL=https://boaterpracticetest.com node build.mjs`.

| File | What it holds |
|---|---|
| `src/data/states.json` | State guides (facts, steps, FAQ, official sources) and the list of all states |
| `src/data/questions-general.json` | Practice questions |
| `src/guides/guides.mjs` | Study guides |
| `src/assets/app.js` | Practice test and equipment checker widgets |
| `src/assets/site.css` | Styles |

Deploy on Cloudflare Pages with build command `STAGING=0 node build.mjs` and output directory `dist`.
