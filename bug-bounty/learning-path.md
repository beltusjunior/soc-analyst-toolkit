# Learning Path

Build skill on targets that are **made to be attacked** before going near a real program. Everything below is free or has a useful free tier.

## 1. Foundations

| Resource | What you get |
|---|---|
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | The standard free course on web vulnerabilities, with hands-on labs for each class |
| [OWASP Top 10](https://owasp.org/Top10/) | The most common web application risks and how they're prevented |
| [OWASP Web Security Testing Guide](https://owasp.org/www-project-web-security-testing-guide/) | The reference for structured, professional web testing |
| [TryHackMe](https://tryhackme.com) | Guided rooms, good for networking and Linux basics too |

## 2. Practice apps (run them locally)

| App | Notes |
|---|---|
| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | Modern web app with a built-in score board of challenges |
| [DVWA](https://github.com/digininja/DVWA) | Classic vulnerable PHP app with adjustable difficulty |
| [OWASP crAPI](https://github.com/OWASP/crAPI) | Deliberately vulnerable API, close to modern bounty targets |

Run these on your own machine or in a VM, never exposed to the internet.

## 3. Challenges and CTFs

| Resource | Notes |
|---|---|
| [Hack The Box](https://www.hackthebox.com) | Retired machines with write-ups; harder than TryHackMe |
| [PicoCTF](https://picoctf.org) | Beginner-friendly, available all year |
| [CTFtime](https://ctftime.org) | Calendar of upcoming CTF competitions |

## 4. Reading real reports

Disclosed reports teach what programs actually pay for and what a good report looks like.

- [HackerOne Hacktivity](https://hackerone.com/hacktivity): publicly disclosed reports
- [Bugcrowd University](https://www.bugcrowd.com/hackers/bugcrowd-university/): free training from the platform

## 5. First real programs

- Start with **VDPs** (vulnerability disclosure programs, no payout) and broad-scope public programs: less competition, real experience, and reputation points that unlock private invites.
- Keep notes on every program: what you tested, what you found, what was a duplicate.
- Use [`scope-checklist.md`](scope-checklist.md) and [`report-template.md`](report-template.md) every time.
